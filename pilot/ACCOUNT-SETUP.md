Keep the username **peunderscrutiny**. Set the profile's public **Name** to **PE Under Scrutiny**.

- In the desktop screen shown, try **Meta Account → Profiles → the Instagram profile → Name**.
- If that path is unavailable, use the Instagram mobile app: **Profile → Edit profile → Name**. Some versions redirect name editing to Meta's profile settings.

This changes the public profile name. It does not erase Meta's private account/verification records or guarantee that the account cannot be associated with its operator.

## 3. Switch to Creator

In Instagram's settings, look for **Account type and tools** or search settings for **professional**. Labels vary by app/version.

1. If **Switch to professional account** appears, choose it.
2. Choose **Creator** for this independent editorial account.
3. Choose a suitable available category, such as **Digital creator**. Category visibility can usually be hidden separately.
4. If you already see **Creator tools** or **Business tools**, the account is already professional. A Business account can also support this manual workflow; there is no need to change type solely to match these instructions.
5. Confirm that professional insights/tools are available. Do not assume conversion worked just because the profile editor opens.

Professional accounts are intended for a public audience. Public branding, recovery/verification details, and optional public contact fields are different settings.

Log into **@PEUnderScrutiny** only in Meta's official login flow and complete any requested verification there. Alternatively, the Instagram professional profile may offer a **Page** connection in its edit-profile/business information section.

Confirm both the intended Facebook Page and **@PEUnderScrutiny** appear as connected assets, and that you have permission to create Instagram posts. Do not infer success from being logged into Facebook alone. This manual scheduling setup does not require creating a Meta developer app or collecting an API token.

If a Page connection is not yet available, the account can still be prepared for manual Instagram posting. A paid scheduler is not needed just to continue setup.
